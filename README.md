# TRPG 地雷チェックツール（GitHub Pages版）

TRPGセッション前に  
**シナリオに含まれる要素（いわゆる地雷）を、内容を直接明かさずに確認する**  
ためのシンプルなWebツールです。

GitHub Pages上で動作し、**サーバー・CGI・追加費用は不要**です。

---

## できること

### GM向け
- シナリオに含まれる要素をチェック
- 内容を直接見せずに判定できる **配布用JSON** を生成
- 含有要素数が分からないよう **ダミートークン（固定64個）** を使用

### PL向け
- GMから配布されたJSONを貼り付けるだけ
- 各項目を  
  **むしろ好き / 問題ない / 好ましくない / 確実に避けたい**  
  の4択で指定
- 結果は  
  - 問題要素があるかどうか  
  - 好みのシナリオと言えそうか  
  のみが表示され、**具体的な内容は分からない**

---

## ファイル構成

- `gm.html`  
  → GM用（シナリオ要素チェック・配布JSON生成）

- `check.html`  
  → PL用（4択チェック・判定）

---

## 使い方

### 1. GM側

1. `gm.html` を開く
2. シナリオに含まれる要素にチェック
3. 「生成する」を押す
4. 出力された **配布用JSON** をPLに渡す  
   （このJSONだけで判定可能）

---

### 2. PL側

1. `check.html` を開く
2. GMから受け取った **配布用JSON** を貼り付け
3. 各項目を4択で選ぶ
4. 「判定する」を押す

---

## 判定結果について

- **確実に避けたい要素が含まれている場合**
  - 「確実に避けたい要素が含まれています。」

- **好ましくない要素が含まれている場合**
  - 「好ましくない要素が含まれています。」

- **上記がなく、かつ「むしろ好き」が含まれる場合**
  - 「好みのシナリオと言えるかもしれません。」

- **どれにも該当しない場合**
  - 「（判定上）問題となる要素は検出されませんでした。」

※ 具体的な項目名や数は表示されません。

---

## 技術的な注意点

- JavaScript（ブラウザ内）だけで動作します
- 外部通信は行いません
- 判定には HMAC（SHA-256）を使用しています
- tokens は常に **64個固定（ダミー含む）** のため、
  含有要素数は推測できません
