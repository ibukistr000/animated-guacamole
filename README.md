# TRPG セッション確認ツール

TRPGセッション前に、GMがシナリオ要素を選び、PLが自分の苦手・好みを入力して、具体的なシナリオ内容を直接見ずに判定する静的Webツールです。

GitHub Pagesでそのまま動作します。サーバー通信、外部API、外部ライブラリは使いません。

## できること

- 地雷チェックと好み判定の両方に使えます。
- GMはPLに見せてよい公開情報と、直接見せない隠し判定タグを分けて入力できます。
- GMは任意追加項目を追加できます。追加項目名はPL側の入力表に表示されます。
- 想定プレイ時間は「時間」単位の数値で入力します。
- PLは5択で各項目への反応を選びます。
- 判定結果には具体的な該当項目名、カテゴリ名、該当数を表示しません。
- GMへ相談するためのコピペ文を表示します。
- 標準タグのみの場合は、低文字数の短縮コードとPL用URLも生成できます。

## ファイル構成

- `index.html`
  - GM用 / PL用を画面内で切り替えて使う本体です。
- `gm.html`
  - 旧URL互換用。`index.html#gm` へ移動します。
- `check.html`
  - 旧URL互換用。`index.html#check` へ移動します。
- `tags.js`
  - タグセット、公開情報定義、回答選択肢、固定トークン数を管理します。
- `items.csv`
  - 回答選択肢、公開情報、隠し判定タグの一覧です。

## 配布JSON

生成される通常JSONには次の情報が含まれます。コピーしやすいよう、通常JSONは改行なしで出力します。

- `v`
- `tagSetVersion`
- `salt`
- `key`
- `tokens`
- `publicInfo`

`tokens` は常に128個固定です。実際に含まれる隠し判定タグの数が分かりにくいよう、ダミートークンを追加します。

標準タグのみの場合は、短縮コードも生成されます。短縮コードは文字数を優先するため、通常JSONより技術的な秘匿性は低くなります。短縮コードは現在の `tags.js` の並びを前提にします。公開情報も短い番号列として圧縮します。任意追加項目がある場合は、項目名リストをPLに渡す必要があるため通常JSONを使ってください。

PL用URLは `index.html#check=...` の形式です。URLを開くとPL用画面に切り替わり、短縮コードが自動入力されます。

## タグセット更新

タグ定義は `tags.js` に集約されています。`gm.html` と `check.html` は同じ `tags.js` を参照するため、ID不一致を起こしにくい構成です。

隠し判定タグや公開情報定義を変更した場合は、`tags.js` の `tagSetVersion` を変更してください。PL側で配布JSONの `tagSetVersion` と現在の `tagSetVersion` が異なる場合、警告を表示します。警告後も判定自体は可能です。

## 互換性

旧JSONを読み込んだ場合、`tagSetVersion` がないことを警告します。

旧JSONでも `salt` / `key` / `tokens` があれば、現在のタグ定義で可能な範囲の判定を行います。ただし旧タグセットとの完全互換は保証しません。

## 注意

本ツールは善意の利用を前提としたネタバレ軽減ツールであり、技術的な完全秘匿は保証しません。

配布JSONには判定に必要な `key` が含まれるため、技術的に詳しい人が解析を試みる可能性までは防げません。最終的な参加判断や配慮は、GMとPLのコミュニケーションを優先してください。
